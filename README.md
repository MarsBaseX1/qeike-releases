# Qeike 安装包与更新

这里只存放 Qeike 的 Windows 安装包和更新信息文件（version.json），供下载和软件内自动更新使用。

## 下载

👉 [下载最新版本](https://github.com/MarsBaseX1/qeike-releases/releases/latest)

在页面下方的“Assets”里点击 `Qeike-Setup-版本号.exe` 下载，运行后按提示安装即可。
如果 Windows 提示“已保护你的电脑”，点「更多信息 → 仍要运行」。

## 激活

安装后第一次打开需要输入**卡密**激活，卡密请向销售方获取。

## 更新

1.0.1 及以后的版本会自动检查更新，也可以在「设置 → 软件更新」里手动检查。
1.0.0 用户请手动下载安装一次最新版本，之后就能自动更新了。
